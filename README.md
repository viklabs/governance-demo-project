# Governed car ETL demo project

This repository is only the sample data-engineering project. It does not contain or deploy the Streamlit Project Registry App.

It creates and refreshes:

- `it_dev.sample_project.car_makes`
- `it_dev.sample_project.car_models`
- `it_prod.sample_project.car_makes`
- `it_prod.sample_project.car_models`
- one serverless Lakeflow Job in each workspace

The required governance tags are:

- `project_tag=<project ID generated by the v2 Registry App>`
- `environment=dev|prod`

## Demo branch model

For this small demonstration, both the registered development branch and production branch are `main`.

1. Push code to `main`.
2. Approve the project in the Registry App.
3. Create a release in the App for the exact `main` commit SHA.
4. Run workflow **01** to deploy that exact SHA to `it-dev`, execute the serverless job, apply/read back tags, and move the release to `READY_FOR_APPROVAL`.
5. Approve the exact release in the App.
6. Run workflow **02** to reauthorize and deploy the same SHA to `it-prod`.

The production workflow cannot pass its authorization step unless the exact release is approved in the App.

See the accompanying assistant instructions for GitHub variables, secrets, permissions, and execution steps.
